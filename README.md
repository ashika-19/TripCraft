# ✈️ TripCraft — Smart Travel Planner

Plan your next adventure with TripCraft! A React-based travel planning web application designed to help users organize trips, explore destinations, manage budgets, build itineraries, and prepare for their journeys in one place.

## 🌍 About the Project

TripCraft makes travel planning easier by bringing essential trip-planning tools together in a single application. From exploring destinations to organizing daily itineraries and tracking packing tasks, the application helps users plan their journeys more efficiently.

## ✨ Features

* 🏠 **Home Dashboard** — Access the main travel-planning features.
* 🗺️ **Explore Destinations** — Browse destinations and discover places to visit.
* 🧳 **Trip Management** — Organize and manage your planned trips.
* 📅 **Itinerary Builder** — Create and organize travel plans.
* 💰 **Budget Planner** — Estimate and manage travel expenses.
* 🎒 **Packing Checklist** — Keep track of essential items before travelling.
* 💾 **Local Data Storage** — Save supported trip information in the browser using local storage.

## 🛠️ Tech Stack

* **Language:** JavaScript (ES6+)

## 🚀 Getting Started

Follow these steps to run TripCraft on your local machine.

### Prerequisites

* [Node.js](https://nodejs.org/) (includes npm)
* Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ashika-19/TripCraft.git
```

**2. Navigate to the project directory**

```bash
cd TripCraft
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173/
```
